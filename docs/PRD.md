# PRD: 솜(SOM) 백엔드 A

## 목표
사용자가 하루 체크인과 선택 연동 데이터를 안전하게 맡기고, 홈·대화·루틴·마이 화면이 B의 계산·AI 결과를 안정적으로 받을 수 있게 하는 공개 API와 데이터 보호 체계를 만든다.

## 사용자
- 지친 신호를 알아차리고 싶은 취업 준비생·사회 초년생 (웹앱, 브라우저로 사용)
- API 소비자: 프론트엔드 / 내부 소비자: 백엔드 B(engine)

## 핵심 기능 (A 담당, P0)
1. 계정: 회원가입(아이디 4~13자, 비밀번호 10~12자)·로그인·로그아웃·본인 조회, 세션 만료 (A-01)
2. 동의: 필수 약관 3종 + 연동 소스별 선택 동의, 허용/철회 이력과 정책 버전 저장 (A-02)
3. 하루 체크인 3문항 저장, 하루 1건, KST 기준, 재제출 처리 (A-03)
4. 연동 데이터 수신 계약: 동의한 소스만, 결측은 null, MVP는 데모 데이터 (A-04)
5. 홈·기록 조회: 오늘 상태, 이번 주(월~일) 변화, 7/30일 기록 (A-05)
6. 대화 메시지·카드 저장과 날짜별 조회, 마음 정리 기록 저장 (A-06)
7. 루틴 목록·시작/완료/건너뜀 기록(멱등), 주간 이행, 마음 정리 잠금 해제 (A-07)
8. 연결 해제, 데이터 삭제, 탈퇴(연쇄 삭제), 알림 설정 (A-08)
9. 공통: 인증·입력 검증·에러 형식·요청 ID·요청 횟수 제한·OpenAPI 문서 (A-09)

## MVP 제외 사항
- 피로도 산식·추천 로직·LLM 호출 구현 (B 담당 — A는 Mock만)
- 실제 기기 연동(수면·걸음·사용시간)과 캘린더 OAuth (웹앱이라 MVP는 데모 데이터)
- 아이디/비밀번호 찾기, 소셜 로그인, 실제 알림 발송(웹 푸시)
- 익명 경험 나누기 '털 담요'

## 디자인
- 백엔드 저장소라 UI 작업 없음. 화면에서 확정된 문구·선택지·흐름은 `/spec/A_SPEC.md`에 정리돼 있다.
- 제품 원칙: 비진단형. 점수·털 무게는 앱 내부 환산 지표이며 진단·치료를 시사하는 필드명·문구를 쓰지 않는다.
